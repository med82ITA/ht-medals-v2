# 🏆 HT Medals v2

HT Medals is an unofficial web application dedicated to the history of **Hattrick National Team competitions**.

The project collects medals, rankings, historical records and statistics for National Teams and U21 National Teams, providing an easy and modern way to explore the history of Hattrick.

> Built with React + Vite.

## 🚀 Development

Clone the repository:

```bash
git clone https://github.com/med82ITA/ht-medals-v2.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
